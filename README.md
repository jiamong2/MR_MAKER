# MR MAKER for ui.clover

<img src="assets/icon.png" width="96" align="right" alt="아이콘">

Windows · macOS 에서 동작하는 **AI 음원 분리 · MR 제작 데스크톱 프로그램**입니다.
Meta AI 의 [Demucs](https://github.com/adefossez/demucs) 또는 고급 엔진 BS-RoFormer 로 노래를 보컬·드럼·베이스·기타·피아노 등으로 나누고,
프로그램 안에서 바로 들어 보면서 원하는 악기만 빼고 MR(반주)을 만들고, 키(-12 ~ +12)도 바꿀 수 있습니다.
인터넷 없이 내 컴퓨터에서 처리되며, 음원이 외부로 전송되지 않습니다.

## 주요 기능

| 구분 | 내용 |
|---|---|
| 분리 모드 | **2-Stem** 보컬 / 반주 · **4-Stem** 보컬 / 드럼 / 베이스 / 기타 악기 · **6-Stem** 보컬 / 드럼 / 베이스 / 기타 / 피아노 / 나머지 |
| AI 엔진 | **기본 (Demucs)** — 빠르고 안정적, 상업적 이용 가능(MIT) · **고급 (BS-RoFormer)** — 피아노·기타 분리가 크게 좋아짐, 첫 사용 시 약 667MB 다운로드, GPU 권장, 개인 용도 |
| 고품질 모드 | Demucs: 미세조정 모델 4개(htdemucs_ft) + 겹침 50% · 6-Stem 은 4-Stem 결과의 '기타 악기'만 6-Stem 모델로 다시 나누는 2단계 방식 · RoFormer: 겹침 4배 |
| 재생 | 모든 트랙 동시 재생, 트랙별 **M**(음소거) · **S**(솔로) · 볼륨, 파형 클릭으로 위치 이동, 파형 확대/축소(최대 16배) |
| MR 만들기 | 뺄 악기를 고르면 **원본 − 뺀 악기** 로 계산해 저장 → 남는 악기는 AI 를 거치지 않은 원본 음질 그대로 (예: 보컬 제외 = 노래방 MR) |
| 키 조절 | **-12 ~ +12 반음**, 템포는 그대로. 재생·MR·트랙 저장에 모두 적용, 드럼은 원래 음높이 유지(선택) |
| 저장 | WAV 24-bit(기본) · WAV 32-bit float · FLAC · WAV 16-bit · MP3 320kbps. 원본 샘플레이트(48kHz 등) 그대로 저장, 클리핑 자동 방지 |
| 가속 | NVIDIA GPU(CUDA) · Apple Silicon GPU(Metal) 자동 사용, 실패 시 CPU 로 자동 재처리 |
| 안정성 | 처리 중에도 화면이 멈추지 않음, 언제든 취소, 메모리·디스크 부족 사전 안내 |
| 입력 형식 | MP3, WAV, FLAC, M4A, AAC, OGG, OPUS, AIFF, WMA, 동영상(MP4, MOV, MKV …)의 오디오 |

## 설치

[Releases](../../releases) 또는 GitHub Actions 빌드 결과(Artifacts)에서 내 컴퓨터에 맞는 파일을 받습니다.

| 컴퓨터 | 파일 |
|---|---|
| Windows 10/11 (64비트), NVIDIA 그래픽카드 있음 | `MRMaker-…-windows-x64-cuda-setup.exe` (+ 같은 폴더의 `.bin` 파일) |
| Windows 10/11 (64비트), 그 외 | `MRMaker-…-windows-x64-cpu-setup.exe` |
| Mac (M1·M2·M3·M4 등 Apple Silicon) | `MRMaker-…-macos-arm64.dmg` |
| Mac (Intel) | `MRMaker-…-macos-x86_64.dmg` |

Python, FFmpeg, PyTorch 등은 모두 포함되어 있어 따로 설치할 필요가 없습니다.

**Windows** — 설치 파일을 실행합니다. 관리자 권한 없이 설치됩니다.
"Windows의 PC 보호" 창이 뜨면 *추가 정보 → 실행* 을 누릅니다 (코드 서명 전 빌드의 경우).
설치 없이 쓰려면 `…-portable.zip` 을 풀고 `MRMaker.exe` 를 실행합니다.
예전 *Music Separator* 를 쓰던 PC 에 설치하면 자동으로 교체되며, 설정과 내려받은 AI 모델은 그대로 유지됩니다.

**macOS** — DMG 를 열고 *MR MAKER for ui.clover* 를 *Applications* 폴더로 끌어다 놓습니다.
공증(Notarization)되지 않은 빌드라면 처음 한 번 *Control+클릭 → 열기* 를 누르거나
*시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기* 를 누릅니다. macOS 12 이상이 필요합니다.

## 사용 방법

1. 음악 파일을 창에 끌어다 놓거나 **파일 열기**를 누릅니다.
2. 왼쪽에서 **2-Stem / 4-Stem / 6-Stem** 과 **AI 엔진**을 고르고 **분리 시작**을 누릅니다.
   - 기본 엔진(Demucs)은 모델이 포함되어 있어 바로 시작합니다. 고급 엔진(BS-RoFormer)은 처음 한 번 약 667MB 를 내려받습니다.
   - 진행률과 남은 시간이 표시되고, **취소**로 언제든 멈출 수 있습니다.
3. 분리가 끝나면 **▶ (Space)** 로 재생합니다.
   - **M** 음소거, **S** 솔로(이 트랙만), 슬라이더로 볼륨(0~150%), 슬라이더 더블클릭 = 100%
   - 파형이나 위쪽 시간 눈금을 클릭/드래그하면 그 위치로 이동합니다. `Home` = 처음으로
   - `Ctrl`(⌘)+휠 또는 타임라인 오른쪽 위 −/+ 로 확대, `Shift`+휠로 좌우 이동
4. **MR 만들기**: 뺄 악기 버튼(빨간 취소선 = 제외)을 고른 뒤 **미리듣기**로 확인하고 **MR 저장**.
   *트랙 볼륨 설정 반영*을 켜면 각 트랙 볼륨 슬라이더 값이 MR 에 적용됩니다.
5. **키 조절**: −/+ 버튼이나 슬라이더로 반음 단위(−12 ~ +12)로 바꿉니다. 잠시 변환한 뒤 재생에 바로 반영되고,
   이후 저장하는 MR·트랙에도 적용됩니다(파일 이름에 `[Key +2]` 처럼 표시). **원래 키** 로 되돌립니다.
6. **저장**(아래 막대): 형식을 고르고 **선택한 트랙 저장**(트랙 카드의 스위치가 켜진 트랙) 또는 **전체 트랙 저장**. 저장 폴더는 **설정…** 에서 바꿉니다.
   파일은 `저장 폴더/곡 이름/곡 이름 - 보컬 (Vocals).wav` 처럼 저장됩니다.

### 분리 품질 · 음질 안내

- 모든 트랙을 더하면 **원본과 정확히 같아지도록** 마지막 트랙(반주 / 기타 악기 / 나머지 악기)을 '원본 − 나머지 트랙'으로 계산합니다.
  그래서 MR 은 AI 가 다시 만든 소리가 아니라 원본에서 뺀 악기만 덜어낸 소리입니다.
- 저장은 원본 샘플레이트로 하고(설정에서 끌 수 있음), 합친 소리가 0dBFS 를 넘으면 모든 파일에 같은 비율로 살짝 줄여 클리핑을 막습니다.
  WAV 32-bit float 는 줄이지 않고 그대로 저장합니다.
- **4-Stem(Demucs)** 의 '기타 악기'에는 기타·피아노·신스·현악기 등이 함께 들어갑니다.
- **6-Stem(Demucs)** 은 4-Stem 으로 보컬·드럼·베이스를 먼저 분리한 뒤 '기타 악기'만 6-Stem 모델로 다시 나눕니다.
  기타는 쓸 만하지만 피아노는 아직 약한 편입니다. **피아노가 중요하면 고급 엔진(BS-RoFormer)** 을 쓰세요.
- **고급 엔진(BS-RoFormer SW)** 은 6개 악기를 한 번에 분리하며 피아노·기타 품질이 크게 좋습니다. 대신 CPU 에서는 곡 길이의 수 배~10배 이상 걸리므로
  NVIDIA GPU 나 Apple Silicon 을 권장합니다. 모델 사용 조건이 명시되지 않은 커뮤니티 모델이라 **개인 용도**로만 사용하세요.
- 리버브가 강한 보컬, 보컬과 같은 음역의 악기(색소폰, 리드 신스), 라이브 녹음은 잔향이 남을 수 있습니다.
- 처리 시간(대략): NVIDIA GPU 는 4분 곡 기준 수십 초, Apple Silicon 은 1분 안팎, CPU 는 코어 수에 따라 1~5분 이상.
  고품질 모드는 2~4배 더 걸립니다.

### 인터넷이 없는 PC 에서 쓰기

기본 배포 파일에는 htdemucs(2·4-Stem)와 htdemucs_6s(6-Stem) 모델이 포함되어 있어 바로 오프라인으로 쓸 수 있습니다.
고품질 모델(htdemucs_ft)이나 고급 엔진(bs_roformer_sw)처럼 포함되지 않은 모델은 인터넷이 되는 PC 에서 한 번 받은 뒤
*⋯ 메뉴 → AI 모델 폴더 열기* 의 폴더를 복사해 오프라인 PC 에서 *⋯ 메뉴 → AI 모델 가져오기* 로 넣으면 됩니다.

| | 모델 저장 위치 |
|---|---|
| Windows | `%LOCALAPPDATA%\MusicSeparator\models` |
| macOS | `~/Library/Application Support/Music Separator/models` |

### 문제 해결

| 증상 | 해결 |
|---|---|
| "GPU 처리 중 문제가 발생하여 CPU로 다시 처리합니다" | 그래픽 드라이버를 최신으로 업데이트하세요. 처리 결과는 CPU 로 정상 완료됩니다. |
| 메모리 부족 경고 | 다른 프로그램을 닫거나 곡을 짧게 잘라 주세요. 4분 곡 기준 약 3GB 여유 메모리가 필요합니다. |
| 소리가 안 남 | 출력 장치(스피커/헤드폰)를 확인하세요. 재생이 안 되어도 분리·저장은 정상 동작합니다. |
| 모델 다운로드 실패 | 회사 방화벽이 `huggingface.co` / `dl.fbaipublicfiles.com` / `github.com` 을 막는 경우입니다. 위의 오프라인 방법을 쓰세요. 고급 엔진은 `BS-Roformer-SW.ckpt` 파일을 직접 받아 *AI 모델 가져오기* 로 넣을 수도 있습니다. |
| 키 조절이 느림 | 곡 전체를 고음질로 변환하므로 4분 곡 기준 수십 초 걸립니다. 한 번 변환한 키는 기억해 두었다가 바로 바꿉니다. |
| 기타 오류 | *오른쪽 위 ⋯ 메뉴 → 로그 폴더 열기* 의 `music_separator.log` 를 확인하세요. |
