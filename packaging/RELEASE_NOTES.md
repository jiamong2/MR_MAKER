## MR MAKER for ui.clover

음원 파일이나 YouTube 주소 하나로 **보컬** 또는 **반주(MR)** 를 추출하고, 키(−12 ~ +12)를 바꿔 저장하는 프로그램입니다.

### 설치 파일 선택
| 컴퓨터 | 파일 |
|---|---|
| Windows, NVIDIA 그래픽카드(RTX 20·GTX 16 시리즈 이상) | `MRMaker-…-windows-x64-cuda.msi` + 같은 이름으로 시작하는 `.cab` 파일들을 같은 폴더에 받은 뒤 .msi 실행 |
| Windows, 그 외 | `MRMaker-…-windows-x64-cpu.msi` (권장) 또는 `MRMaker-…-windows-x64-cpu-setup.exe` |
| Mac (M1~M4, Apple Silicon) | `MRMaker-…-macos-arm64.dmg` |
| Mac (Intel) | `MRMaker-…-macos-x86_64.dmg` |

### v1.3.8 변경 사항
- **템포 조절 범위를 50% ~ 200% 로 넓혔습니다** (반 박자 ~ 두 배 박자). 100% 에서 멀어질수록 소리가 조금씩 부자연스러워질 수 있습니다.
- [절반] / [2배] 버튼을 목표 BPM 옆으로 옮겼고, 이제 **지금 빠르기(목표 BPM)를 반 / 두 배로** 바꿉니다 (예: 100% → 50% / 200%). [원래 빠르기] 를 누르면 항상 원곡 빠르기로 돌아갑니다.
- 원곡 BPM 은 자동 추정값을 고정해서 보여 주고, 목표 BPM 만 직접 입력할 수 있습니다.

### v1.3.7 변경 사항
- **템포(빠르기) 조절**: 고급 옵션 화면에 "4. 템포 조절" 이 생겼습니다. 음높이는 그대로 두고 빠르기만 70% ~ 130% 로 바꿉니다 (−/+ 1%, −10% / −5% / +5% / +10% 버튼, [원래 빠르기]).
  - 재생과 저장에 모두 적용되고, 키 조절과 함께 쓰면 한 번에 처리합니다. 저장 파일 이름에 `[Tempo 90%]` 처럼 표시됩니다.
  - **원곡 BPM 참고 표시**: 곡을 불러오면 원곡 BPM 을 자동으로 추정해 "원곡 / 목표 BPM" 으로 보여 줍니다. 목표 BPM 을 넣으면 빠르기(%)로 바꿔 적용합니다.
  - 추정값은 참고용이라 반이나 두 배로 잡힐 수 있어요 ([절반] / [2배] 버튼으로 바로 고침). 알고 있는 BPM 이 있으면 직접 고쳐 넣으면 됩니다. 박자가 뚜렷하지 않은 곡은 "모름" 으로 표시합니다.
  - 템포는 원곡 대비 배율로 바꾸기 때문에, BPM 추정이 틀리거나 곡 중간에 템포가 흔들려도 결과물은 그대로 비례해서 바뀝니다.

### v1.3.6 변경 사항
- **[실험] 화음 따기 개선 — 결과가 "주 선율 + 화음" 으로 바뀌었습니다** (메뉴 ⋯ → "실험실: 화음 따기…")
  - **주 선율**: 매 순간 가장 잘 들리는 목소리를 혼자 부르는 부분까지 끊김 없이 담습니다. 예전에는 한 사람의 솔로가 위/아래 파일로 뒤섞여 들어가는 문제가 있었습니다.
  - **화음**: 두 목소리가 실제로 함께 나는 구간의 두 번째 목소리만 담습니다. 숨소리·잔향·짧은 잡음이 화음으로 잡히던 문제를 줄였습니다.
  - **음표 정리**: 미끄러지듯 부르는 사이에 생기던 짧은 반음 조각(지나가는 음)을 옆 음에 합칩니다.
  - **확인용 오디오**: 주 선율 = 보컬 − 화음, 화음 = 함께 부르는 구간만. 혼자 부르는 구간의 화음 파일은 무음입니다.
  - 정답 트랙이 있는 시험곡(남자 솔로 → 여자 솔로 → 함께, 잔향 포함)에서: 솔로 목소리가 한 파일에 담긴 비율 48% → 94%, 가짜 화음 28% → 4%, 솔로 음표 일치율(F) 0.58 → 0.90. 함께 부르는 구간에서 두 목소리를 동시에 맞힌 비율은 88% → 73% 로 조금 낮아졌지만, 찾은 화음 음의 정확도는 80% → 92% 로 올랐습니다.
- 재생 중 트랙 파형 위의 재생 위치 세로선이 움직이지 않던 문제를 고쳤습니다 (긴 곡이나 좁은 창에서, Windows·Mac 공통).

### v1.3.5 변경 사항
- **[실험] 화음 따기 (위 · 아래 성부 MIDI)**: 메뉴(⋯) → "실험실: 화음 따기…" 에서 듀엣 곡 보컬의 두 성부를 찾아 **위 성부 / 아래 성부 MIDI** 로 받아 적습니다. 두 목소리가 함께 나는 곳은 높은 음이 위, 낮은 음이 아래 성부로 들어가고, 한 사람만 부르는 부분은 위 성부에 들어갑니다.
  - 함께 저장: 반주(MR), 각 성부를 귀로 확인하는 **확인용 오디오** 2개 (음질은 거칠고, 둘을 더하면 원래 보컬)
  - MIDI 는 120 BPM 기준으로 원곡과 시간이 맞춰져 있습니다 (DAW 프로젝트 템포 120, 오디오와 함께 1마디에 놓기).
  - 남/여 합창 예제(정답 트랙 있음)에서 두 성부를 동시에 맞힌 비율 87%, 찾은 음의 95% 가 정답이었습니다. 세 성부 이상이면 가장 잘 들리는 두 성부만, 같은 음을 옥타브로 겹쳐 부르면 한 성부만 나올 수 있습니다.
  - 처음 사용할 때 음정 추적 모델 RMVPE(약 173MB, MIT)를 내려받습니다.
- 이전 실험 기능 "듀엣 분리 (남/여)" 는 화음 따기로 바뀌었습니다. 예전에 받은 남/여 분리 모델(약 503MB)은 자동으로 지웁니다.

### v1.3.4 변경 사항
- 파일 정보 아래에 표시되던 예상 처리 시간을 없앴습니다 (실제와 차이가 커서).
- CUDA(GPU) 버전은 이제 MSI(+ .cab) 설치 파일만 제공합니다. 예전에 CUDA 를 setup.exe 로 설치했다면 기존 프로그램을 지우고 MSI 로 한 번 새로 설치해 주세요.

### v1.3.3 변경 사항
- **다른 곡을 고르면 처음 상태로**: 결과가 나온 뒤 다른 파일·YouTube 주소를 넣거나 선택을 해제하면, 이전 결과를 지우고 버튼이 [음원 추출 시작] 으로 돌아갑니다. 키는 0 으로 돌아가고 '보컬만/반주만' 선택은 그대로 유지됩니다.
- **완료 화면에서 바로 미리 듣기**: 저장한 파일을 홈 화면에서 바로 재생·탐색할 수 있습니다 (스페이스바로도 재생/정지).
- **작업 완료 알림**: 다른 창을 보고 있을 때 작업이 끝나면 작업 표시줄 아이콘이 깜빡이고 알림음이 울립니다 (설정에서 알림음 끄기 가능).
- 홈 화면 아래쪽에 저장 형식과 저장 위치만 간단히 표시합니다.

### v1.3.2 변경 사항
- **음원 파일도 분리 없이 키만 바꿔 저장**: 음원 파일을 넣고 키를 조절하면 "분리하지 않고 원곡에 키 조절만 적용해 저장" 옵션을 선택할 수 있습니다. (YouTube 입력은 키 조절과 상관없이 원본 그대로 저장 가능)

### v1.3.1 수정 사항
- **처리 방식대로 AI 모델이 동작하도록 수정**: 고급 옵션의 'AI 모델' 선택을 없앴습니다. 예전에 이 칸에서 BS-RoFormer 를 골라 둔 경우 '속도 우선'이어도 느린 품질 모델로 처리되던 문제가 있었습니다. 이제 속도 우선 = Demucs, 품질 우선·최고 품질 = BS-RoFormer SW 로만 동작합니다.
- **다시 설치할 때의 동작 정리**: 더 새 버전은 기존 버전을 교체하고, 같은 버전은 다시 설치(덮어쓰기)하며, 이전 버전은 설치하지 않습니다 (MSI·setup.exe 모두).
- 다시 설치·업데이트 후 작업 표시줄에 고정한 아이콘이 빈칸으로 바뀌던 문제를 고쳤습니다 (MSI 설치판).

### v1.3.0 변경 사항

### v1.2.9 변경 사항

### v1.2.5 수정 사항
- CPU 버전과 CUDA 버전이 설정을 공유해, CUDA 버전에서 고른 '품질 우선'이 CPU 버전에도 적용되던 문제를 고쳤습니다. 이제 설치 종류별로 따로 저장하고, 직접 바꾼 경우에만 기억합니다. (이번 업데이트 후 처리 방식은 각 버전의 기본값으로 한 번 돌아갑니다.)
- 프로그램을 삭제하면 설정도 함께 지워집니다. (내려받은 AI 모델은 재설치를 위해 유지)

### v1.2.4 수정 사항
- 메뉴(⋯)에서 일부 글자가 깨져 보이던 문제(예: '로그' → '로ㄱ')를 근본적으로 고쳤습니다. 메뉴 글자를 글꼴 렌더러 대신 벡터로 직접 그립니다.

### v1.2.3 변경 사항
- **자동 업데이트 알림**: 프로그램을 켤 때 새 버전이 있으면 화면 위쪽에 알림이 뜹니다. [업데이트]를 누르면 내려받아 설치한 뒤 다시 실행합니다. (메뉴 ⋯ → 새 버전 확인)
- 메뉴 글씨 일부가 깨져 보이던 문제(예: '로그 폴더 열기')를 고쳤습니다.

### v1.2.2 수정 사항

  (긴 제목을 자른 끝이 공백이면 Windows가 폴더 이름에서 공백을 지워 저장 경로가 어긋났습니다.)

기본 처리 방식: CPU 버전·Intel Mac = 속도 우선, CUDA 버전·Apple Silicon = 품질 우선 (고급 옵션에서 변경 가능)

### 설치 시 보안 경고 안내
최초 설치 시 Windows의 "PC 보호" 또는 "알 수 없는 게시자" 경고가 표시될 수 있습니다. 이는 개인이 개발한 소프트웨어로서
유료 코드 서명 인증서를 적용하지 않았기 때문에 운영체제가 표시하는 일반적인 안내이며, 프로그램의 결함이나 위험성과는 무관합니다.
- **Windows**: 경고 창에서 **[추가 정보] → [실행]**
- **macOS**: 최초 실행 시 앱을 **Control+클릭 → [열기]** (처음 한 번만)

설치 파일은 GitHub 공식 서버에서 공개 소스 코드로 자동 생성되며, 모든 음원 처리는 사용자의 컴퓨터 안에서만 이루어집니다.

### 이용 시 유의사항
- YouTube 입력 기능은 이용자가 권리를 보유하거나 다운로드가 허용된 콘텐츠에 한하여 사용하시기 바랍니다.
- 분리된 음원은 모임 내 개인 연습 용도로만 사용하시기 바랍니다.
- 본 프로그램은 자유롭게 배포·공유하실 수 있으나, 프로그램 및 이를 통해 생성된 음원의 **영리적 이용은 금지됩니다.**
